# Raiz Viva — Loja de suplementos naturais

Site estático (HTML, CSS e JS puro) com catálogo, filtros por categoria, busca, carrinho e pedido enviado pelo WhatsApp.

## Como usar
- Abra `index.html` no navegador. Não precisa instalar nada.
- **Número do WhatsApp:** em `products.js`, troque `WHATSAPP_NUMBER` (DDI + DDD + número, só dígitos).
- **Produtos e preços:** edite a lista `PRODUCTS` em `products.js`.

## Publicar
Funciona em GitHub Pages, Netlify ou Vercel: basta publicar a pasta `suplementos-naturais/`.

## Fontes das informações
- NIH Office of Dietary Supplements: https://ods.od.nih.gov/factsheets/list-all/
- NCCIH (NIH): https://www.nccih.nih.gov/health/herbsataglance
- ANVISA, RDC 243/2018 e IN 28/2018 (regras para suplementos alimentares)

> Antes de vender de verdade, confira se os rótulos e textos de marketing seguem a IN 28/2018 da ANVISA (só alegações permitidas, nenhuma promessa de tratar doenças).
