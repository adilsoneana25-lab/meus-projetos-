# meus-projetos-

## Adega Prima (`adega/`)
Site de adega de bebidas com layout inspirado no apple.com: barra de navegação global translúcida, seções hero, grade de destaques e rodapé com notas, mapa do site e links legais.

Abra `adega/index.html` no navegador; não precisa de instalação.

- Menu de tela cheia, busca e rodapé em acordeão no celular
- Sacola com contador e aviso
- Verificação de idade (+18) e avisos legais de consumo de álcool
- Fotos reais do Unsplash (licença gratuita, uso comercial permitido) em `adega/img/`, com créditos no rodapé
